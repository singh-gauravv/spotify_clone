# 🎵 Spotify Clone

A static clone of the Spotify web player, built using only HTML and CSS. This project replicates the look and feel of Spotify's user interface, showcasing frontend design skills and responsive layout techniques.

## 🚀 Features

- Replicated Spotify homepage layout
- Sidebar navigation menu
- Playlist section and album artwork
- Music player UI at the bottom
- Fully responsive design (desktop-first approach)

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
